# MovieBox API - Code Examples

This folder has simple examples of how to use the MovieBox API.

## What's Here

- `download-movie-cli.py` - Example of downloading a movie using command line
- `download-series-cli.py` - Example of downloading a TV series using command line
- `fetch-page-contents.py` - Example of getting page content
- `extractors-benchmark.py` - Performance test example

## How to Use

1. Look at the example files
2. Copy the code you need
3. Change the movie/TV show names
4. Run the code

## For Beginners

If you're new to coding:
- Start with simple examples
- Change only the movie names
- Ask for help if stuck
